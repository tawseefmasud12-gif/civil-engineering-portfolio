# St George's Field Raised Walkway
**Module:** CIVE1665 Integrated Design Project · Project 4  
**Location:** St George's Field, University of Leeds  
**Project type:** Group design proposal developed in Revit

## Overview
Developed an accessible raised walkway concept connecting access points across St George's Field, including a route associated with the Sir William Henry Bragg Building. The brief asked for a continuous accessible route and specified constraints around clear width, elevated sections and the opportunity for a small viewing platform.

## Design considerations
The proposal explored structural stability, the relationship between deck and supporting structure, connection details, handrails, material choice, durability, maintenance, visual impact and a plausible construction method. Site context — particularly existing trees and landscape — formed part of how the route was represented and evaluated.

## Revit and technical skills developed
- Developed the walkway design in Revit and used the model to communicate the scheme.
- Worked with plans, longitudinal sections, elevations and sectional construction details.
- Created 3D views in context to explain the route, support arrangement and how the design sits within the site.
- Connected model geometry with technical drawings to explain structure and construction, not only appearance.

## Collaboration
Worked with group members to research precedents, develop concepts, review options and progress a common proposal. Discussions required balancing accessibility, visual quality, material/cost considerations and structural practicality.

## Key learning
The project improved my understanding of how route geometry, accessibility, structural support, connection details and site context need to be resolved together. It also strengthened my confidence in using Revit-generated drawings and visualisations to communicate engineering decisions.
